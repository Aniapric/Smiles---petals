# 🌸 Smiles & Petals

**Smiles & Petals** is a responsive, multi-page floral-themed website developed as part of the *Web Techniques* course. The project focuses on semantic HTML, modern CSS layout techniques, JavaScript-driven interactivity, and basic AJAX integration.

## Pages
- **Home** – landing page with navigation menu, catch phrase, gallery, and contact section  
- **Our Magical Garden** – informational page presenting different flower types and their meanings  
- **Flower Shop** – product-style layout displaying pre-made bouquets  
- **My Cart** – interactive shopping cart with order summary and checkout functionality  
- **My Account** – user registration, login, logout, and session management  

## Features
- Semantic HTML5 structure  
- Responsive design using CSS Grid and Flexbox  
- Consistent visual theme, typography, and color palette  
- Dropdown navigation menu  
- Card-based layouts and image galleries  
- Hover effects and subtle CSS animations  
- JavaScript-powered shopping cart and order system  
- User authentication and session handling using `localStorage`  
- Data loading using AJAX (`fetch`) from JSON files  

## Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)  
- AJAX (Fetch API)  
- CSS Grid & Flexbox  
- Google Fonts  
- LocalStorage
